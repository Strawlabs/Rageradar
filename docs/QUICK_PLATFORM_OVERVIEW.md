# RageRadar - Quick Platform Overview

## 🎯 What Does RageRadar Do?

**In one sentence:** RageRadar tells you what people are saying about your brand across the internet and whether they're happy or angry about it.

---

## 🚀 The Simple Version

```
1. You type a brand name (e.g., "Apple")
2. We search 27+ platforms (Reddit, Twitter, YouTube, etc.)
3. AI reads all the mentions
4. We tell you: Are people happy? Angry? Neutral?
5. You see results in a beautiful dashboard
```

---

## 📊 The 3 Core Components

### **1. Search Engine** 🔍
- Searches 27+ platforms simultaneously
- Finds up to 50 recent mentions
- Extracts text, links, and timestamps

### **2. AI Sentiment Analyzer** 🧠
- Reads each mention
- Determines if it's positive, negative, or neutral
- Calculates a score (0-100)
- Detects sarcasm and context

### **3. Rage Index Calculator** 😡
- Our unique metric
- Combines negative sentiment + intensity
- Tells you if your brand is in trouble
- 0-50 = Good, 50-70 = Caution, 70-100 = Alert!
