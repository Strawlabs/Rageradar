# SEO Maintenance Guide for RageRadar

## Daily Tasks

### Monitor Performance
- Check Google Search Console for errors
- Review Google Analytics for traffic anomalies
- Monitor Core Web Vitals in PageSpeed Insights

## Weekly Tasks

### Content Updates
- Publish 1-2 blog posts (1500+ words each)
- Update FAQ section with new questions
- Share content on social media

### Technical Checks
- Test all internal links
- Check for broken external links
- Verify sitemap is up to date
- Monitor page load speeds

## Monthly Tasks

### SEO Audit
- Run Lighthouse audit on key pages
- Check for duplicate content
- Review and update meta descriptions
- Analyze keyword rankings
- Review backlink profile

### Content Strategy
- Research new keywords to target
- Update old blog posts with fresh content
- Create new landing pages for target keywords
- Analyze competitor content

### Technical Maintenance
- Update structured data if needed
- Check mobile usability
- Review and optimize images
- Update sitemap.xml with new pages

## Quarterly Tasks

### Comprehensive Review
- Full technical SEO audit
- Content gap analysis
- Competitor analysis
- Backlink outreach campaign
- Update SEO strategy based on results

### Performance Optimization
- Analyze and optimize Core Web Vitals
- Review and update page speed optimizations
- Test and improve mobile experience
- Optimize conversion funnels

## Key Metrics to Track

### Traffic Metrics
- Organic sessions
- New vs returning visitors
- Pages per session
- Average session duration
- Bounce rate

### Ranking Metrics
- Keyword positions (top 10 keywords)
- Featured snippet appearances
- Rich result impressions
- Click-through rate (CTR)

### Conversion Metrics
- Signup conversion rate
- Trial-to-paid conversion
- Goal completions
- Revenue from organic traffic

### Technical Metrics
- Core Web Vitals (LCP, FID, CLS)
- Page load time
- Mobile usability score
- Crawl errors
- Index coverage

## SEO Best Practices Checklist

### For Every New Page
- [ ] Unique, descriptive title tag (50-60 characters)
- [ ] Compelling meta description (150-160 characters)
- [ ] Proper heading hierarchy (H1 → H2 → H3)
- [ ] Keyword in first paragraph
- [ ] Internal links to related pages
- [ ] Optimized images with alt text
- [ ] Mobile-responsive design
- [ ] Fast loading time (< 3 seconds)
- [ ] Structured data where applicable
- [ ] Canonical URL set
- [ ] Social sharing tags (OG, Twitter)

### For Every Blog Post
- [ ] Target keyword research completed
- [ ] Keyword in title, H1, and first paragraph
- [ ] 1500+ words of quality content
- [ ] 2-3 internal links
- [ ] 1-2 external authoritative links
- [ ] Featured image optimized
- [ ] Meta description written
- [ ] Categories and tags assigned
- [ ] Social sharing buttons included
- [ ] Call-to-action included

## Common SEO Issues to Avoid

### Content Issues
- ❌ Duplicate content
- ❌ Thin content (< 300 words)
- ❌ Keyword stuffing
- ❌ Missing or duplicate meta descriptions
- ❌ Broken internal links

### Technical Issues
- ❌ Slow page load times
- ❌ Mobile usability problems
- ❌ Missing structured data
- ❌ Broken canonical tags
- ❌ 404 errors
- ❌ Redirect chains
- ❌ Missing alt text on images

### User Experience Issues
- ❌ High bounce rate
- ❌ Poor mobile experience
- ❌ Intrusive interstitials
- ❌ Difficult navigation
- ❌ Unclear CTAs

## Emergency Response Plan

### If Rankings Drop Suddenly
1. Check Google Search Console for manual actions
2. Review recent site changes
3. Check for technical errors (404s, server errors)
4. Verify robots.txt and sitemap
5. Check for algorithm updates
6. Review backlink profile for toxic links

### If Traffic Drops
1. Check Google Analytics for data accuracy
2. Review Search Console for crawl errors
3. Check if pages are indexed
4. Verify tracking code is working
5. Look for seasonal trends
6. Check competitor activity

### If Page Speed Degrades
1. Run Lighthouse audit
2. Check for new scripts or plugins
3. Optimize images
4. Review third-party scripts
5. Check server response time
6. Enable caching

## Quick Reference: SEO Components

### Meta Tags Template
```html
<title>Primary Keyword - Secondary Keyword | RageRadar</title>
<meta name="description" content="Compelling description with keywords (150-160 chars)" />
<meta name="keywords" content="keyword1, keyword2, keyword3" />
```

### Heading Structure
```html
<h1>Main Page Title (One per page)</h1>
  <h2>Major Section</h2>
    <h3>Subsection</h3>
    <h3>Subsection</h3>
  <h2>Major Section</h2>
    <h3>Subsection</h3>
```

### Image Optimization
```html
<img 
  src="image.webp" 
  alt="Descriptive alt text with keywords"
  width="800"
  height="600"
  loading="lazy"
/>
```

### Internal Linking
- Link to related pages using descriptive anchor text
- Aim for 2-5 internal links per page
- Use keyword-rich anchor text naturally
- Link to both newer and older content
