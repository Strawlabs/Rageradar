# RageRadar Knowledge Base

## Getting Started

### What is RageRadar?

RageRadar is an AI-powered sentiment analysis platform that helps you monitor and understand public emotional reactions to your brand across 27+ platforms.

**Key Features:**
- 🎭 **Multi-Emotion Detection:** Identify 28+ specific emotions (anger, frustration, joy, etc.)
- 📊 **Rage Index 2.0:** Quantify sentiment on a 0-100 scale
- 🔍 **Platform Monitoring:** Reddit, YouTube, Product Hunt, App Stores, and more
- 📈 **Trendline Analysis:** Track emotional changes over time
- 💡 **Automated Insights:** Get actionable recommendations
- 🎯 **Event Tracking:** Monitor product launches, crises, announcements

---

## Quick Start Guide

### 1. Create Your First Analysis

1. Click **"New Analysis"** button
2. Enter your brand name
3. Select platforms to monitor (Pro plan)
4. Click **"Analyze"**
5. Wait 30-60 seconds for results

### 2. Understanding Your Results

**Rage Index:**
- 0-19: Minimal rage (😊 Great!)
- 20-39: Low rage (🙂 Good)
- 40-59: Moderate rage (😐 Watch closely)
- 60-79: High rage (😟 Take action)
- 80-100: Critical rage (🚨 Urgent!)

**Emotions:**
- View top 3-5 emotions detected
- See confidence scores
- Review emotion distribution

**Insights:**
- Read automated recommendations
- Prioritize by severity (High/Medium/Low)
- Take suggested actions

## Features Guide

### Multi-Emotion Detection

**What it does:**
Analyzes text to identify specific emotions beyond simple positive/negative.

**Supported Emotions:**
- **Rage:** anger, fury, frustration, annoyance
- **Negative:** disgust, disappointment, sadness, fear
- **Positive:** joy, love, admiration, excitement, gratitude
- **Neutral:** surprise, confusion, realization

**How to use:**
1. Run any analysis
2. View "Emotions" tab
3. See breakdown by emotion type
4. Click emotion to see example mentions

**Available on:** Starter, Pro, Enterprise

---

### Event Tracking

**What it does:**
Monitor emotional changes before, during, and after specific events.

**Event Types:**
- 🚀 Product Launch
- 🔥 Crisis/Incident
- 📢 Announcement
- 🔄 Update/Change
- ⚠️ Controversy

**How to use:**
1. Go to "Events" tab
2. Click "Create Event"
3. Enter event details:
   - Event name
   - Event date
   - Event type
   - Pre/post monitoring period
4. Click "Create & Analyze"
5. View pre/during/post comparison

**Available on:** Pro, Enterprise

---

### Theme Extraction

**What it does:**
Automatically identifies recurring topics in high-rage mentions.

**How it works:**
- Uses NLP to extract keywords
- Groups similar terms
- Ranks by intensity (frequency × rage)
- Shows example mentions

**How to use:**
1. Run analysis with 50+ mentions
2. View "Themes" tab
3. See top rage topics
4. Click theme to see examples
5. Address top themes first

**Available on:** Pro, Enterprise

---

### Trendline Analysis

**What it does:**
Tracks Rage Index and emotions over time to identify patterns.

**Features:**
- Daily/weekly/monthly views
- Spike detection
- Moving averages
- Volatility measurement
- Trend direction

**How to use:**
1. Go to "Trendline" tab
2. Select time period (7/30/90 days)
3. View chart
4. Hover for details
5. Click spikes to investigate

**Available on:** Pro (30 days), Enterprise (90+ days)

## Troubleshooting

### No Results Found

**Possible causes:**
- Brand name too generic
- No recent mentions
- Platform restrictions

**Solutions:**
- Use specific brand name
- Add product name
- Try different platforms
- Expand time range

### Low Mention Count

**Possible causes:**
- Niche brand
- New brand
- Limited platform selection

**Solutions:**
- Enable more platforms (Pro plan)
- Use broader search terms
- Check spelling
- Try related products

### Inaccurate Emotions

**Possible causes:**
- Sarcasm in text
- Mixed emotions
- Context-specific language

**Solutions:**
- Review examples manually
- Report inaccuracies (we improve!)
- Use theme extraction for context

## FAQ

**Q: How often is data updated?**
A: Real-time for new analyses. Historical data refreshes every 24 hours.

**Q: Can I export data?**
A: Yes! CSV (Starter+), PDF (Pro+), JSON/Excel (Enterprise).

**Q: How many brands can I monitor?**
A: Unlimited on all paid plans. 5 analyses/month on Free.

**Q: What's the difference between analysis and brand?**
A: One brand can have multiple analyses over time.

**Q: Can I track competitors?**
A: Yes! Monitor any public brand.

**Q: Is my data private?**
A: Yes. We only analyze public data. Your analyses are private.

**Q: Can I get alerts?**
A: Yes! Email alerts for rage spikes (Pro+).

**Q: What's the API rate limit?**
A: 100k requests/month (Pro), unlimited (Enterprise).

**Q: How accurate is theme extraction?**
A: Theme extraction uses advanced NLP with 80-85% accuracy. It identifies recurring topics in high-rage mentions. Best results with 50+ mentions.

**Q: How many data points are needed for trendlines?**
A: Minimum 7 analyses over 7 days. More data points = better trend accuracy. Pro gets 30-day trendlines, Enterprise gets 90+ days.

**Q: Can I customize automated insights?**
A: Enterprise plan offers custom insight models tailored to your industry. Pro/Starter plans use our standard 8 insight types.

**Q: What types of insights are generated?**
A: 8 types: Rage Spikes, Trends, Spike Detection, Themes, Platform Hotspots, Volume Changes, Emotion Shifts, and Summary insights.

**Q: Do themes work for all languages?**
A: Currently optimized for English. Multi-language support coming in Q1 2026.

**Q: How often are trendlines updated?**
A: Trendlines update with each new analysis. Run analyses daily for best trend tracking.
